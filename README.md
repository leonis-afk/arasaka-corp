# Arasaka Corporation — Requisition Portal

An interactive, single-page cyberpunk web application inspired by the *Cyberpunk 2077* universe. Built using vanilla JavaScript, HTML5, and Tailwind CSS, deployed via GitHub Pages.

## 🚀 Key Features

* **Cyberware Catalog**: Dynamic catalog rendering subdermal implants, neuralware, and arms upgrades.
* **Interactive Cart State**: Real-time total calculation, quantity updates, and custom modal views.
* **Dynamic Search & Filters**: Client-side filtering by category and search queries.
* **Canvas 3D Tower Graphics**: Custom HTML5 Canvas rendering for atmospheric HUD elements.
* **Ambient Audio Integration**: Background audio player with user controls.

---

## 🛠 Tech Stack

* **Front-End Framework**: Vanilla JavaScript (ES6+)
* **Styling**: Tailwind CSS (CDN integration) & FontAwesome icons
* **Typography**: Orbitron & Rajdhani Google Fonts
* **Hosting**: GitHub Pages
